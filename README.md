# 隐患治理台账系统 — 本地部署版

局域网内使用的隐患台账系统，数据存放在本机 **PostgreSQL**，无需联网、无需云服务。

---

## 一、访问方式

| 场景 | 地址 |
|------|------|
| 本机访问 | http://localhost:3000 |
| **局域网访问**（同事用这个） | **http://192.168.2.22:3000** |

> 局域网内的其他电脑，直接用浏览器打开 `http://192.168.2.22:3000` 即可。
> 若打不开，检查服务器电脑的防火墙是否放行了 3000 端口（见"常见问题"）。

**默认账号**：`admin` / `123456`（首次登录建议立即修改密码）

## 三、启动与停止

### 开机自启（已配置）
系统已注册 Windows 计划任务 **`HazardLedger`**，开机 30 秒后自动启动，**无需人工干预**。
- 查看状态：以管理员打开 CMD，执行 `schtasks /Query /TN HazardLedger /V /FO LIST`
- 手动启动：`schtasks /Run /TN HazardLedger`
- 停止服务：`schtasks /End /TN HazardLedger`

### 手动启动（不依赖自启）
双击 `start.bat`，窗口保持打开即服务运行中，关闭窗口即停止。

### 修改配置
编辑 `config.json`：
```json
{
  "port": 3000,                 // 服务端口（改后需重启服务）
  "host": "0.0.0.0",            // 0.0.0.0 = 允许局域网访问
  "db": {
    "host": "127.0.0.1",
    "port": 5432,
    "user": "postgres",
    "password": "在此填写你的数据库口令",
    "database": "hazard_ledger"
  }
}
```

## 四、数据库

- **PostgreSQL 17.6**，服务名 `PostgreSQL-17`（开机自启，以 LocalSystem 运行）
- **数据目录：`D:\hazard-ledger-lan\pgdata`**（已迁入本项目，随项目走）
- 程序目录：`D:\PostgreSQL\pgsql`（二进制，位置未变）
- 库名：`hazard_ledger`（首次启动自动创建；表也自动创建）
- 用户：`postgres` ｜ 密码：见 `config.json`（`db.password`）
- 连接：`127.0.0.1:5432`

> 因为数据已在本项目内，**拷贝整个 `D:\hazard-ledger-lan` 文件夹即带走完整系统**（程序 + 数据库）。

数据表：
- `hazard` — 隐患台账主表
- `users` — 用户与角色
- `counters` — 隐患编号计数器（按日）
- `sessions` — 登录会话令牌（7 天有效期）
- `operation_log` — 操作日志（谁在何时做了什么）

### 自动备份（已配置）
计划任务 **`HazardLedgerBackup`**，**每天 02:00** 自动备份，输出到 `backup\hazard_YYYYMMDD_HHMMSS.sql`，**保留最近 14 份**（更早的自动删除）。

```bat
REM 手动备份一次
schtasks /Run /TN HazardLedgerBackup
REM 或直接执行
D:\hazard-ledger-lan\backup-db.bat
```

### 备份数据库（手动导出）
```bat
"D:\PostgreSQL\pgsql\bin\pg_dump.exe" -U postgres -h 127.0.0.1 -d hazard_ledger -f "D:\backup\hazard.sql"
```
（需输入数据库密码）

### 恢复数据库
```bat
"D:\PostgreSQL\pgsql\bin\psql.exe" -U postgres -h 127.0.0.1 -d hazard_ledger -f "备份文件.sql"
```

## 五、功能说明

- **统计看板**：隐患总数 / 未闭环 / 逾期 / 完成率 + 等级分布、类别分布、月度趋势图
  - **指标卡可点击**：隐患总数 → 全部台账；未闭环数 → 筛选「未闭环」的台账；逾期数 → 筛选「逾期」的台账
  - **整改完成率**：卡片做成**进度条**，按完成率分四档配色 —— <30% 红(偏低) / 30–60% 橙(一般) / 60–85% 黄(良好) / ≥85% 绿(优秀)
  - **闭环时长分布**（位于月度趋势**左侧**）：**横轴=闭环耗时天数，纵轴=隐患条数**，柱状图，柱顶标注条数
  - **月度趋势**：新增隐患 / 闭环隐患两条折线，**每个数据点标注数值**
- **隐患台账**：按等级、类别、状态、日期区间、关键词筛选；分页；逾期整行红色高亮；**点击任意一行进入详情**
- **打印**：按当前筛选条件生成 A4 横向打印稿（含标题、筛选条件与条数），直接调用系统打印
  - 打印稿不包含制表人/制表时间等信息
  - 若打印件底部出现**网址、页码**，那是**浏览器自带的页眉页脚**：在打印设置中取消勾选「页眉和页脚」即可（该设置浏览器会记住）
- **导出 Excel**：按当前筛选条件，一键导出 `.xlsx`（另支持 `format=csv`）
- **隐患登记**：基本信息 / 隐患信息 / 整改信息
  - **隐患照片**（隐患信息内）、**整改照片**（整改信息内）：最多各 6 张，选择后自动压缩上传、可单张移除、点击缩略图放大
  - 上传前浏览器端压缩（长边 1600px / JPEG 0.82），文件存放于 `uploads\`，数据库仅存路径
- **隐患详情 + 完整状态流转**：`待整改 → 整改中 → 已闭环`
  - 「开始整改」：由录入人员 / 安全管理员操作
  - 「复查闭环」：由复查人员 / 安全管理员操作（**必须先进入"整改中"**）
  - **打印隐患详情单**：A4 纵向、四个分区（基本/隐患/整改/复查）、含三方签字栏
- **个人中心**（侧边栏 / 用户下拉菜单进入）：展示我的账号信息 + 三类待办提醒，侧边栏图标带**待办数角标**
  - **整改提醒**：我为整改责任人且未闭环的隐患
  - **复查提醒**：状态为「整改中」、等待复查闭环的隐患
  - **闭环提醒**：已逾期或 3 天内到期、尚未闭环的隐患（催办）
  - 提醒列表可点击直达隐患详情
- **用户管理**：角色分配、重置密码（管理员）
- **系统维护**（用户管理页底部，管理员可见）：查看图片文件总数 / 占用空间 / 被引用数 / 无引用数，一键**清理无引用图片**（仅上传但未提交表单的图片）
- **操作日志**：记录**谁在何时登记、整改、复查、删除、导出**了什么（管理员/安全管理员可查）

**角色权限**（服务端强制校验，越权返回 403）：
| 角色 | 权限 |
|------|------|
| 录入人员 entry | 登记隐患、开始整改、查看台账 |
| 复查人员 reviewer | 复查闭环、查看台账 |
| 安全管理员 safety_admin | 整改、复查、删除隐患、查看台账 |
| 系统管理员 admin | 全部权限 + **用户管理 / 操作日志 / 系统维护**（仅 admin 可见） |

## 六、常见问题

**Q：局域网其他电脑打不开？**
1. 确认服务在运行：服务器上执行 `netstat -ano | findstr :3000`，应看到 `0.0.0.0:3000 LISTENING`
2. 防火墙规则**已由 `install-autostart.bat` 自动添加**（规则名 `HazardLedger 3000`，入站 TCP 3000）。
   若被误删，以管理员 CMD 重新添加：
   ```bat
   netsh advfirewall firewall add rule name="HazardLedger 3000" dir=in action=allow protocol=TCP localport=3000 profile=any
   ```
3. 确认两台电脑在同一网段，且能互相 ping 通

**Q：服务启动失败？**
查看 `server-out.log`。常见原因：
- PostgreSQL 服务未启动 → `net start PostgreSQL-17`
- `config.json` 中数据库密码不对

**Q：端口 3000 被占用？**
改 `config.json` 的 `port`，然后重启服务。

**Q：忘了 admin 密码？**
管理员登录后可在"用户管理"里重置其他用户密码；若 admin 本身密码丢失，可用 `psql` 直接改 `users` 表，或删除该记录后重启服务（会自动重建 admin/123456）。

## 七、技术说明

- 服务端：Node.js 22+，仅依赖 `pg` 一个 npm 包，无框架
- 前端：原生 HTML/CSS/JS，图表为纯 SVG 自绘，**无任何外部 CDN 依赖**（局域网内完全离线可用）
- **安全**：
  - 登录采用**服务端会话令牌**（登录返回 token，前端存于 localStorage，后续请求带 `Authorization: Bearer <token>`）；未登录访问任何接口一律返回 401
  - **角色权限在服务端强制校验**（返回 403）：用户管理仅管理员、删除隐患限安全管理员、复查闭环限复查人员等
  - 密码存储为 SHA-256(salt + password)
  - 令牌有效期 7 天，登出即失效
- 隐患编号：`YH-YYYYMMDD-NNNN`，数据库原子自增，不会撞号
- 逾期判定：统一使用**本地日期**（列表状态、筛选、统计三处口径一致）
- **响应式适配**（手机 / 平板 / 桌面）：
  - ≤1080px：指标卡与图表两列、台账筛选区两列
  - ≤760px：侧边栏收为抽屉（左上角菜单按钮展开）、指标卡/表单/详情/筛选区**全部单列**、页头操作按钮独占一行并等宽、台账表格**横向滑动**并显示「← 左右滑动 →」提示、分页纵向排列
  - 各页面均无页面级横向滚动
